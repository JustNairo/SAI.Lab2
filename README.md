Приложения для лабораторной работы с генетическим алгоритмом. 
# Суть приложения
Есть список задач, для которого необходимо составить расписание на день, т.е. решить какие задачи будут выполняться в этот день и определить для них время начала. 

У каждой задачи есть продолжительность и приоритет. Есть также задачи с фиксированным временем, которые должны находиться в определённом месте ва расписании и их нельзя передвинуть.

# Скрины работы
Главное окно до составления расписания можно увидеть слева на картинке, два варианта расписания - справа. ПРи каждом запуске алгоритма расписания могут быть разными
